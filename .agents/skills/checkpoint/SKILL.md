# Checkpoint

1. Собери по сессии: что сделано и проверено, что в работе (файл и место), что дальше (2–3 шага), какие решения приняты и почему.
2. Обнови `TASK.md` по скелету протокола: «Текущее состояние», «Следующие шаги», «Решения»; обнови дату в `Обновлено`.
3. Прогони `tools/memory-check.ps1`, если он есть. Ошибки исправь; предупреждения назови одной строкой.
4. Закоммить память: `git add TASK.md && git commit -m "memory: <задача> — <состояние>"`. Код добавляй в коммит только если пользователь просил коммит кода.
5. Ответь одной строкой: `Сохранено: <задача> — <состояние>`.

Ограничения: не пересказывай диалог, не дублируй историю чата, не добавляй секреты, не спрашивай разрешения на запись — это служебное действие. Если проект не под git — пропусти шаг 4 и скажи об этом одной строкой.
