# Resume

1. Прочитай `TASK.md` в корне проекта. Файла нет — сообщи одной строкой и предложи инициализацию; работу не выдумывай.
2. Если есть `tools/memory-check.ps1` — запусти его. Учти результат, но не пересказывай отчёт целиком.
3. Сверь память с репозиторием: `git log -5 --oneline` и `git status --short`. Если код менялся позже даты в `Обновлено` — скажи об этом.
4. Ответь 3–5 строками ровно в этой форме:

   ```
   Цель: …
   Сделано: …
   Дальше: …
   — идём?
   ```

5. Жди «идём» или «да». До подтверждения ничего не делай.
6. После подтверждения — первый следующий шаг из памяти, без повторного исследования.

Ограничения: не пересказывать историю, не перечислять файлы, не предлагать альтернативные планы, не переписывать память «по-своему». Если память противоречит репозиторию — доверяй репозиторию и запиши расхождение в одну строку.
