- **Решения:**
  | Что | Почему |
  |---|---|
  | Триггеры живут в `AGENTS.md`, а не в `TASK.md` | `AGENTS.md` загружается всегда; список слов внутри `TASK.md` открывался бы только по слову из него самого — замкнутый круг. |
  | Resume оформлен скиллом `.agents/skills/resume` | Harness сканирует `.agents/skills` проекта и отдаёт скиллы модели и человеку — штатный механизм вместо недокументированных настроек редактора. |
  | Добавлена проверка свежести по git | Без неё устаревшая память выглядит как актуальная — самый дорогой отказ протокола. |
  | Pre-commit хук, а не напоминание агенту | Хук срабатывает независимо от того, вспомнила ли модель про память. |
  | Шаблон отделён от живой памяти | `TASK.md` этого репозитория — одновременно пример заполненной памяти; копировать нужно `templates/TASK.md`. |
  | Запрет пересказа диалога в памяти | Память должна сжимать; иначе новый чат читает вторую, худшую версию истории. |
  | Длинные прогоны отданы `goal` | Harness продолжает раунды сам, протоколу не нужно изобретать автономность. |
